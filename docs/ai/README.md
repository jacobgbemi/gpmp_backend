# GlintPM Private — AI Documentation

This directory defines the strategic, architectural, security, evaluation, and governance baseline for using AI within GlintPM Private.

## Documents

- `ai-strategy.md` — AI objectives, principles, and adoption strategy
- `ai-use-cases.md` — appropriate AI use cases across project controls
- `ai-architecture.md` — conceptual AI architecture and integration patterns
- `prompt-guidelines.md` — standards for prompts and AI instructions
- `ai-data-access.md` — AI access to project and organizational data
- `ai-security.md` — AI-specific security controls
- `ai-evaluation.md` — quality, accuracy, and safety evaluation
- `ai-human-oversight.md` — human review and decision accountability

> **Implementation note:** This documentation is a governance and architecture baseline. It does not claim that AI functionality is currently implemented. Actual models, providers, integrations, permissions, prompts, data flows, and controls must be verified against the application code and deployment configuration.
