# AI Strategy

**Status:** AI strategy baseline  
**Last updated:** 2026-10-07

## Purpose

Define how AI should create useful, controlled value within GlintPM Private without replacing project-controls accountability.

## Strategic Objective

AI should help project professionals:

- understand project information faster;
- identify patterns and anomalies;
- generate useful summaries;
- investigate project performance;
- improve reporting;
- support forecasting and decision preparation;
- reduce repetitive administrative work.

## Guiding Principles

1. **Decision support, not uncontrolled decision-making.**
2. **Project data remains authoritative.**
3. **Traceability matters.**
4. **Security and tenant isolation are mandatory.**
5. **Human approval is required for consequential actions.**
6. **AI outputs should expose uncertainty where appropriate.**
7. **AI should complement established project-controls methodology.**

## Priority

AI adoption should begin with lower-risk use cases such as:

- summarization;
- report drafting;
- variance explanations;
- data-quality assistance;
- project Q&A;
- action-item extraction.

Higher-risk capabilities such as automated baseline changes, financial decisions, or schedule modifications require stronger controls.

## Success Measures

Evaluate AI by:

- accuracy;
- usefulness;
- time saved;
- adoption;
- user trust;
- hallucination/error rate;
- security incidents;
- human override rate.

## Non-Goals

AI should not independently:

- approve budgets;
- approve baselines;
- alter contractual records;
- authorize payments;
- make personnel decisions;
- modify critical project data without explicit authorization.
