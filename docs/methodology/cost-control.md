# Cost Control

**Status:** Methodology baseline  
**Last updated:** 2026-10-07

## Purpose

Cost control tracks financial performance against the approved budget and forecasts the expected final outcome.

## Core Cost Data

Typical categories include:

- approved budget;
- planned value;
- commitments;
- actual cost;
- accruals;
- forecast;
- estimate at completion;
- variance.

## Cost Control Cycle

```text
Budget
  ↓
Time-Phase
  ↓
Commitments / Actuals
  ↓
Reconcile
  ↓
Variance Analysis
  ↓
Forecast
  ↓
Corrective Action
```

## Cost Breakdown

Costs may be controlled by:

- WBS;
- cost account;
- activity;
- resource;
- contract;
- discipline;
- work package;
- cost type.

## Variance

A variance should always have a defined formula and interpretation.

For example:

```text
Cost Variance = Budget − Actual
```

The project-specific control procedure should define whether positive or negative values are favorable.

## Cost Forecast

Forecasts should consider:

- committed costs;
- actual costs;
- remaining work;
- approved changes;
- risks/opportunities;
- productivity;
- current trends.

## Cost Integrity

Financial values should use appropriate precision and an explicit currency.

Avoid overwriting historical actuals. Corrections should be traceable and authorized.
