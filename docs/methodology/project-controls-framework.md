# Project Controls Framework

**Status:** Methodology baseline  
**Last updated:** 2026-10-07

## Purpose

Project controls provide the systems, processes, data, and analysis required to plan, measure, forecast, and control project performance.

GlintPM Private is intended to bring these activities into a connected project-controls workflow.

## Control Cycle

1. Plan the work.
2. Develop the schedule and budget.
3. Approve the baseline.
4. Collect actual progress and cost.
5. Compare actual performance against the baseline.
6. Analyze variances.
7. Forecast the remaining work.
8. Identify risks and changes.
9. Take corrective action.
10. Report performance.

## Control Principles

- Use a controlled baseline.
- Establish a defined data date.
- Maintain traceable source data.
- Separate planned, actual, and forecast values.
- Analyze both time and cost.
- Record approved changes.
- Use consistent measurement rules.
- Make assumptions visible.
- Preserve historical information.

## Data Chain

```text
Plan → Baseline → Actuals → Variance → Forecast → Decision → Action
```

A strong system should preserve the relationship between each stage.
