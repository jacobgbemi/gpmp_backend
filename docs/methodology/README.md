# GlintPM Private — Project Controls Methodology

This directory defines the project-controls methodology that GlintPM Private is intended to support.

## Documents

- `project-controls-framework.md` — integrated project-controls framework
- `planning.md` — project planning principles and workflow
- `scheduling.md` — schedule development and maintenance
- `baseline-management.md` — baseline creation, approval, and control
- `progress-measurement.md` — progress measurement and status collection
- `cost-control.md` — budget, actuals, commitments, and variance
- `schedule-control.md` — schedule performance and corrective action
- `earned-value-management.md` — EVM concepts and calculations
- `forecasting.md` — time and cost forecasting
- `change-control.md` — controlled management of project changes
- `risk-management.md` — identification, analysis, response, and monitoring
- `reporting.md` — project-controls reporting
- `project-performance.md` — integrated performance evaluation

> **Implementation note:** This methodology describes the intended project-controls model. It is not a claim that every workflow or calculation is already implemented in the application. The implemented code, tests, configuration, approved procedures, and project-specific governance remain authoritative.
