# Progress Measurement

**Status:** Methodology baseline  
**Last updated:** 2026-10-07

## Purpose

Progress measurement converts actual project accomplishment into controlled, comparable performance information.

## Data Date

Every status cycle should have a clearly defined data date.

## Progress Sources

Depending on the project, progress may be measured using:

- activity completion;
- physical quantities;
- milestones;
- weighted milestones;
- physical percentage complete;
- earned value;
- installed quantities;
- documented deliverables.

## Measurement Principles

Progress should be:

- objective;
- repeatable;
- traceable;
- consistent;
- aligned with scope;
- resistant to subjective inflation.

## Example

If an activity has a measured quantity:

```text
Progress % = Actual Quantity / Total Planned Quantity × 100
```

The actual measurement rule depends on the activity and approved progress methodology.

## Status Cycle

```text
Collect Evidence
      ↓
Measure Progress
      ↓
Validate
      ↓
Update Schedule/Cost
      ↓
Calculate Performance
      ↓
Review Variance
```

## Progress Validation

Check:

- supporting evidence;
- quantities;
- dates;
- activity status;
- predecessor logic;
- reporting period;
- approved changes.

## Historical Integrity

Previously approved progress should not be silently rewritten. Corrections should be traceable.
