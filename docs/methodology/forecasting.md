# Forecasting

**Status:** Methodology baseline  
**Last updated:** 2026-10-07

## Purpose

Forecasting estimates the likely future outcome of the project using current performance, remaining work, approved changes, risks, and other relevant information.

## Forecast Types

Common forecasts include:

- completion date;
- estimate at completion;
- remaining duration;
- remaining cost;
- cash flow;
- milestone dates.

## Forecast Cycle

```text
Current Status
     ↓
Actual Performance
     ↓
Remaining Work
     ↓
Risks & Changes
     ↓
Forecast
     ↓
Scenario Analysis
     ↓
Decision
```

## Schedule Forecast

Consider:

- remaining duration;
- productivity;
- critical path;
- float;
- constraints;
- approved changes;
- risks;
- recovery actions.

## Cost Forecast

Consider:

- actual cost;
- commitments;
- remaining budget;
- productivity;
- approved changes;
- risks/opportunities;
- expected remaining expenditure.

## Forecast vs Baseline

The baseline should remain stable unless formally changed.

The forecast should change as project knowledge changes.

## Scenario Analysis

Where supported, users may compare:

- current forecast;
- recovery scenario;
- risk scenario;
- optimistic scenario;
- conservative scenario.

Assumptions behind every scenario should be visible.

## Forecast Governance

Significant forecast changes should be explained, reviewed, and communicated through the project's reporting process.
