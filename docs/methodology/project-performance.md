# Project Performance

**Status:** Methodology baseline  
**Last updated:** 2026-10-07

## Purpose

Project performance evaluates whether the project is achieving its scope, time, cost, and other objectives.

## Integrated Performance

Performance should not be judged from a single metric.

Consider:

- scope;
- schedule;
- cost;
- progress;
- quality;
- risk;
- changes;
- forecast.

## Performance Model

```text
                 PROJECT PERFORMANCE
                         │
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
     Schedule          Cost            Scope
        │                │                │
        └────────────────┼────────────────┘
                         ↓
                     Progress
                         ↓
                 Risk & Change
                         ↓
                    Forecast
                         ↓
                    Decision
```

## Performance Questions

A project-controls review should answer:

1. Are we delivering the planned scope?
2. Are we progressing according to plan?
3. Are we within approved cost?
4. What is the current forecast?
5. What has changed?
6. What risks threaten the outcome?
7. What corrective actions are required?

## Trend Analysis

Review performance across reporting periods rather than relying only on a single snapshot.

Useful trends may include:

- planned vs actual progress;
- cost variance;
- schedule variance;
- CPI/SPI where applicable;
- forecast completion;
- milestone movement;
- risk exposure.

## Corrective Action

When performance deviates materially:

```text
Detect → Analyze → Decide → Act → Monitor
```

Actions should have clear ownership and due dates.

## Performance Governance

Performance metrics should have:

- defined formulas;
- controlled source data;
- clear reporting periods;
- documented assumptions;
- consistent measurement rules.

## Decision Support

The objective of project controls is not merely to produce metrics. It is to provide reliable information early enough for project teams to make better decisions and protect project outcomes.
