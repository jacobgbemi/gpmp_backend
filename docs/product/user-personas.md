# GlintPM Private --- User Personas

## 1. Persona: Project Controls Manager

**Role:** Head/Manager of Project Controls

### Goals

-   Establish reliable project controls
-   Standardize reporting
-   Identify exceptions early
-   Improve management visibility
-   Ensure project teams follow control processes

### Frustrations

-   Inconsistent reports
-   Spreadsheet dependency
-   Late updates
-   Data reconciliation
-   Lack of traceability
-   Difficulty comparing projects

### Needs

-   Portfolio visibility
-   Standardized workflows
-   Auditability
-   Exception dashboards
-   Reporting automation
-   Role-based access

### Key Questions

-   Which projects need attention?
-   What changed this reporting period?
-   Which forecast assumptions changed?
-   Which actions are overdue?

## 2. Persona: Project Planner

**Role:** Planning/Scheduling Engineer

### Goals

-   Maintain reliable schedules
-   Track progress
-   Identify delays
-   Produce accurate reports
-   Explain schedule variance

### Frustrations

-   Chasing progress data
-   Repetitive reporting
-   Multiple versions of schedules
-   Poorly structured project data

### Needs

-   Schedule visibility
-   Baseline comparison
-   Progress tracking
-   Variance analysis
-   Reporting support

### Key Questions

-   What is the current critical path?
-   What activities changed?
-   What is driving delay?
-   What is the forecast completion date?

------------------------------------------------------------------------

## 3. Persona: Cost Engineer

**Role:** Cost Engineer / Cost Controller

### Goals

-   Monitor budget and actuals
-   Forecast final cost
-   Track changes
-   Explain cost variance

### Frustrations

-   Delayed actual-cost data
-   Manual reconciliation
-   Unclear change history
-   Inconsistent forecasts

### Needs

-   Budget/actual/forecast visibility
-   Cost variance
-   Change tracking
-   Audit trail

### Key Questions

-   What is the current forecast?
-   What caused the variance?
-   Which changes are approved?
-   What assumptions drive the forecast?

------------------------------------------------------------------------

## 4. Persona: Project Manager

**Role:** Project Manager

### Goals

-   Deliver the project successfully
-   Understand project health
-   Resolve issues quickly
-   Coordinate stakeholders

### Frustrations

-   Too many disconnected reports
-   Conflicting information
-   Late warnings
-   Unclear ownership

### Needs

-   One consolidated project view
-   Exceptions
-   Risks/issues
-   Actions
-   Decisions
-   Schedule and cost status

### Key Questions

-   Where are we now?
-   What is going wrong?
-   Why?
-   What needs my attention?
-   Who owns the next action?

------------------------------------------------------------------------

## 5. Persona: Project Director / Executive

**Role:** Executive overseeing one or more projects

### Goals

-   Protect project/business outcomes
-   Make timely decisions
-   Understand major risks
-   Allocate management attention

### Frustrations

-   Long reports without clear exceptions
-   Conflicting numbers
-   Lack of confidence in forecasts

### Needs

-   Concise dashboards
-   Exception reporting
-   Forecast visibility
-   Decision-support information

### Key Questions

-   Which projects require intervention?
-   What is the likely outcome?
-   What decisions are pending?
-   What is the financial exposure?

------------------------------------------------------------------------

## 6. Persona: PMO / Governance Lead

**Role:** PMO or Project Governance Lead

### Goals

-   Standardize project practices
-   Improve reporting
-   Maintain governance
-   Compare projects

### Needs

-   Standard workflows
-   Reporting templates
-   Governance data
-   Portfolio visibility
-   Auditability

------------------------------------------------------------------------

## 7. Persona Design Principle

Personas should describe actual customer behavior discovered through
research.

They should be updated when interviews, pilot deployments, or product
analytics reveal different needs.
