# Testing Documentation

This directory defines the testing strategy and standards for GlintPM Private.

The documents describe the intended testing baseline for the Django backend, React frontend, APIs, database interactions, security controls, and critical user workflows. The actual repository, CI configuration, and executable tests remain the source of truth for implemented coverage.
