These documents define the intended architecture and engineering principles. They do not automatically establish that every described capability exists in the current repository.

The actual codebase, tests, configuration, and deployment environment are the source of truth for implementation status.

Major architectural changes should be recorded as Architecture Decision Records under `/docs/decisions/`.
