# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for GlintPM Private.

| ADR | Decision |
|---|---|
| [ADR-001-project-stack.md](ADR-001-project-stack.md) | Project technology stack |
| [ADR-002-database-choice.md](ADR-002-database-choice.md) | PostgreSQL as primary database |
| [ADR-003-authentication-strategy.md](ADR-003-authentication-strategy.md) | Server-controlled authentication |
| [ADR-004-api-design.md](ADR-004-api-design.md) | REST-oriented API |
| [ADR-005-multi-tenancy.md](ADR-005-multi-tenancy.md) | Organization-scoped multi-tenancy |
| [ADR-006-audit-trail.md](ADR-006-audit-trail.md) | Application-level audit trail |

These ADRs are an architectural baseline, not proof that every decision is already implemented. Repository code, tests, dependency configuration, infrastructure, and deployment configuration remain the implementation source of truth.

When a decision changes materially, create a new ADR that explains the change and references the previous decision.
