# Cost Control

**Status:** User guide baseline  
**Last updated:** 2026-10-06

## Purpose

Explain how project budgets and costs can be managed and compared.

## Core Cost Concepts

Typical cost information includes:

- approved budget;
- planned cost;
- actual cost;
- committed cost;
- forecast cost;
- variance.

## Cost Workflow

```text
Budget
  ↓
Cost Loading
  ↓
Actual/Committed Costs
  ↓
Forecast
  ↓
Variance Analysis
  ↓
Cost Report
```

## Cost Categories

Projects may classify costs by:

- WBS;
- cost code;
- resource;
- activity;
- discipline;
- contract/package;
- cost type.

## Currency

Every financial value should have an explicit currency context.

Do not mix currencies in a report without clearly identifying conversion assumptions.

## Variance

A basic variance may be calculated as:

```text
Variance = Budget − Actual
```

The application's exact definitions should be followed because favorable/unfavorable interpretation depends on the metric.

## Cost Data Quality

Before publishing a cost report:

- verify reporting period;
- reconcile source data;
- check duplicate transactions;
- confirm currency;
- review unusual variances;
- confirm approved budget changes.

## Access Control

Only authorized users should create, modify, approve, or export sensitive financial information.
