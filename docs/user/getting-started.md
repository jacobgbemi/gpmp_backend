# Getting Started

**Status:** User guide baseline  
**Last updated:** 2026-10-06

## Purpose

Help a new GlintPM Private user understand the application and complete the first project-controls workflow.

## First Steps

1. Sign in using your assigned account.
2. Confirm your organization/workspace.
3. Review your available permissions.
4. Open or create a project.
5. Configure the project baseline information.
6. Add or import schedule information.
7. Configure cost information where applicable.
8. Record progress.
9. Review reports and dashboards.

## Typical Workflow

```text
Project Setup
    ↓
Schedule Planning
    ↓
Cost Setup
    ↓
Baseline
    ↓
Progress Update
    ↓
Performance Analysis
    ↓
Reports & Dashboards
```

## Navigation

The application is expected to organize work around major project-controls areas such as:

- Projects
- Schedules
- Costs
- Progress
- Risks
- Reports
- Dashboards

The exact navigation depends on the implemented frontend.

## Good Practice

Before entering project data, understand:

- project start and finish dates;
- calendar assumptions;
- WBS structure;
- schedule status/data date;
- approved budget;
- reporting period;
- project currency;
- user permissions.

## Getting Help

When reporting a problem, provide:

- project name or identifier;
- action being attempted;
- expected result;
- actual result;
- approximate time;
- error message/request ID if available.

Never send passwords, tokens, or other secrets when requesting support.
