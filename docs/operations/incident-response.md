# Incident Response

## Purpose
Provide a repeatable response to operational and security incidents.

## Lifecycle
`Prepare → Detect → Triage → Contain → Eradicate/Fix → Recover → Review`

## Severity
SEV-1 critical; SEV-2 significant; SEV-3 limited; SEV-4 minor. Definitions should be aligned with business requirements.

## Response
Confirm incident, determine scope/severity, create record, preserve evidence, stop ongoing damage, communicate, and recover.

For suspected compromise, preserve evidence, isolate affected systems when appropriate, rotate credentials, review access, identify affected data, and follow applicable notification obligations.

## Post-incident
Document timeline, impact, root cause, detection, response, lessons, preventive actions, owners, and deadlines.
