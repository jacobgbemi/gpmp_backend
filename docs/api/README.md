## Important

These documents are an API documentation baseline. Endpoint paths, request/response schemas, authentication mechanisms, and supported operations must be verified against the repository before being treated as implemented contracts.

Backend routes, views, serializers, services, tests, and frontend API clients are the implementation source of truth.
